healpipe: an on-call agent pattern

A runner executes jobs. A sentinel polls failed jobs, investigates them with tools specific to each job type, and then makes a gated, dry-runnable config write and relaunches, or escalates.

  • Guardrails live in code: no QC-threshold edits, no blind retries, capped relaunches
  • Claude scores 7/7, the same as a rules baseline; escalation counts as a success state
  • The recorded Claude run replays in CI with no API key

pipeboard: a small internal tool

A form generated from a YAML schema, background jobs as subprocesses, live log streaming with cancel, and a self-contained HTML report. No agent.

  • Change the YAML and the form changes, with no JavaScript edits
  • A QC setting that removes every cell gives a readable failed job, not a crash

ovary-spatial-tutorial: a Seurat walkthrough

An educational notebook on one published mouse ovary Curio Seeker 3×3 sample (Mantri et al., PNAS 2024; GEO GSE240271): QC, clustering, marker annotation, spatial maps, co-localization and Wilcoxon DE, with "Check your understanding" questions.
